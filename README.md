## 💻 Run Locally

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project:

```bash
cd <repository-name>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in your terminal.
